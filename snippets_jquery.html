📦 Document Ready

$(document).ready(function() {
  // Seu código aqui
});
👆 Clique em botão

$("#meuBotao").click(function() {
  alert("Botão clicado!");
});
🎯 Alterar texto de um elemento

$("#meuElemento").text("Novo texto aqui!");
💡 Toggle visibilidade

$("#elemento").toggle();
🎨 Add / Remove classe CSS

$("#elemento").addClass("ativo");
$("#elemento").removeClass("ativo");
📋 Pegar valor de input

let nome = $("#inputNome").val();
alert("Nome: " + nome);
✍️ Alterar valor de input

$("#inputNome").val("Edson");
🧼 Limpar campo de texto

$("#campoTexto").val("");
🔁 Loop em elementos com classe

$(".item").each(function(index) {
  console.log(index + ": " + $(this).text());
});
📤 Enviar formulário via AJAX

$("#meuForm").submit(function(e) {
  e.preventDefault();
  $.post("enviar.php", $(this).serialize(), function(res) {
    alert("Resposta: " + res);
  });
});
🔄 GET via AJAX

$.get("dados.json", function(data) {
  console.log(data);
});
🎬 FadeIn / FadeOut

$("#mensagem").fadeIn();
$("#mensagem").fadeOut();
📌 Scroll suave até elemento

$('html, body').animate({
  scrollTop: $("#destino").offset().top
}, 800);

O que vem a seguir

  • Document ready: Estrutura básica para garantir que o DOM está carregado
  • Seletores rápidos: Selecionar elementos por id, classe, atributo
  • Eventos comuns: Click, change, submit, hover, keyup
  • Manipulação de classes: addClass, removeClass, toggleClass
  • Mostrar/esconder elementos: show, hide, fadeIn, fadeOut, slideUp, slideDown
  • AJAX simplificado: $.get, $.post, $.ajax com callbacks
  • Validação de formulários: Checar campos vazios, impedir envio
  • Animações: animate para transições customizadas
  • Manipulação de atributos e valores: attr, val, text, html
  • Delegação de eventos: .on para elementos dinâmicos
  • Iteração em listas: $.each para arrays e objetos
  • Encadeamento de métodos: Uso de chaining para múltiplas ações em sequência
