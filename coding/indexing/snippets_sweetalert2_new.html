Select com Validação SweetAlert2

Implementação de select com validação usando SweetAlert2

Swal.fire({
  title: 'Escolha uma opção',
  input: 'select',
  inputOptions: {
    'opcao1': 'Opção 1',
    'opcao2': 'Opção 2',  
    'opcao3': 'Opção 3'
  },
  inputPlaceholder: 'Selecione uma opção',
  showCancelButton: true,
  confirmButtonText: 'Confirmar',
  cancelButtonText: 'Cancelar',
  inputValidator: (value) => {
    return !value && 'Você precisa selecionar uma opção!'
  }
}).then((result) => {
  if (result.isConfirmed) {
    Swal.fire('Sucesso!', `Você escolheu: ${result.value}`, 'success');
  }
});

SweetAlert2

SweetAlert2 é uma biblioteca JavaScript que substitui as caixas de diálogo padrão do navegador (alert, confirm e prompt) por modais bonitos, personalizáveis e responsivos.

Principais funcionalidades:

  • ✅ Substituição elegante para alert(), confirm() e prompt()
  • ✅ Totalmente personalizável com CSS
  • ✅ Suporte a promises/async-await
  • ✅ Animações suaves
  • ✅ Tipos de input: texto, email, senha, número, telefone, range, textarea, select, radio, checkbox, file, url
  • ✅ Timer automático
  • ✅ Validação de formulários
  • ✅ Callbacks customizados
  • ✅ Compatível com todos os navegadores modernos

Instalação via CDN:

<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11"></script>
