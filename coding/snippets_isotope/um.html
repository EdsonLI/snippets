Demonstração completa do Isotope.js + jQuery

Objetivo: Testar visualmente o funcionamento do Isotope.js com filtros dinâmicos usando jQuery e cards de exemplo.

Cada card abaixo pertence a uma "categoria" (HTML, CSS ou JS). Clique nos botões para filtrar!
