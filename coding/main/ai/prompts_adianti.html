Prompts para Modelos & Grids Adianti
🧱 Gerar modelo (TRecord)
Crie uma classe PHP para o Adianti Framework que represente a tabela "clientes" com os campos: id, nome, email, telefone, status, created_at. Use TRecord como base.
📋 Gerar formulário BootstrapForm
Crie uma tela de cadastro para o Adianti usando BootstrapForm com os campos: nome (obrigatório), email (validação de e-mail), telefone (com máscara) e status (combo: ativo/inativo). Inclua botão de salvar com método onSave.
📑 Gerar TDataGrid com filtros
Gere um TDataGrid para listar os dados da tabela 'pedidos' com colunas: id, cliente_id, total, status, data_criacao. Adicione filtros para cliente_id (autocomplete) e status (combo), e uma ação para visualizar detalhes.
🗑️ Ação de exclusão com confirmação
Me mostre como criar uma ação de exclusão em uma TDataGrid do Adianti que exibe confirmação com TQuestion e chama o método onDeleteConfirmado.
🔍 Filtro com persistência
Gere um formulário de busca com campos: nome e status, usando BootstrapFormBuilder no Adianti. Os filtros devem ser armazenados na sessão para manter o estado da pesquisa entre páginas.
🔗 Botão personalizado na grid
Na minha TDataGrid, quero adicionar um botão "PDF" ao lado de cada pedido, que chama o método onGerarPdf passando o ID da linha. Mostre o código.
🔐 Menu lateral com permissões
Gere um menu lateral para um sistema Adianti com as seções: Cadastros, Relatórios, Configurações. Cada item deve verificar se o usuário logado tem permissão usando checkPermission().
📦 Classe de serviço com regras de negócio
Crie uma classe chamada PedidoService no Adianti que contenha métodos para: calcular total do pedido, aplicar desconto, verificar estoque e registrar pedido. Não exibir interface.
📊 Dashboard com cards
Crie um dashboard simples no Adianti com 3 cards horizontais exibindo: Total de clientes, Total de pedidos do mês, e Valor total em aberto. Use TPanelGroup e THTMLRenderer.
