## Variáveis de contexto (#) — visão geral

- **#function**: inclui **o código do método/função onde o cursor está** (não depende do nome).
- **#selection**: inclui **apenas o trecho selecionado**.
- **#file**: inclui **todo o arquivo atual**.
- **#class**: inclui **a classe atual** (quando aplicável).
- **#project**: inclui **contexto do projeto inteiro/workspace**.

### Nota importante (métodos pelo nome)
- Não existe `#onSave`. Para focar em `onSave`, faça **uma destas opções**:
  1) Posicione o cursor **dentro de onSave** e use `#function`.
  2) **Selecione** o código do método e use `#selection`.
  3) Use `#file` e peça explicitamente: "Explique o método **onSave** em #file".
#function — Pega o código da função/método onde o cursor está. Não depende do nome do método.
Explicação estilo “como assim function faz?”:
Ao usar #function, o Copilot Chat “expande” automaticamente o código do método atual (ex.: onSave) e trabalha em cima dele.
