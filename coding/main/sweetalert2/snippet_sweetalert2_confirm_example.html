SweetAlert2
Configuration Params

Here are the keys that you can use if you pass an object into SweetAlert2:

title: Título principal da caixa de alerta (em formato HTML).

titleText: Título do alerta em formato de texto puro (útil para evitar injeção de HTML).

text: Texto simples para descrição do alerta.

html: Conteúdo HTML para o corpo do alerta (tem precedência sobre text).

icon: Ícone do alerta: success, error, warning, info, question.

iconColor: Cor do ícone (ex: #fff).

iconHtml: Conteúdo HTML personalizado para o ícone.

footer: Conteúdo no rodapé do alerta (texto ou HTML).

backdrop: Fundo escurecido (boolean ou string com URL de imagem).

position: Posição do alerta: top, top-start, top-end, center, center-start, center-end, bottom, bottom-start, bottom-end.

grow: Animação de crescimento: row, column, fullscreen ou false.

toast: Exibir como notificação toast (fixado no canto).

showConfirmButton: Exibir botão de confirmação.

showCancelButton: Exibir botão de cancelar.

showDenyButton: Exibir botão de negação (útil para alertas com 3 botões).

confirmButtonText: Texto do botão de confirmar (padrão: 'OK').

cancelButtonText: Texto do botão de cancelar (padrão: 'Cancel').

denyButtonText: Texto do botão de negação (padrão: 'No').

confirmButtonColor: Cor do botão confirmar (padrão: #3085d6).

cancelButtonColor: Cor do botão cancelar (padrão: #aaa).

denyButtonColor: Cor do botão negar (padrão: #dd6b55).

buttonsStyling: Usar os estilos padrões do SweetAlert2.

reverseButtons: Inverter posição dos botões.

focusConfirm: Foco inicial no botão confirmar.

focusCancel: Foco inicial no botão cancelar.

focusDeny: Foco inicial no botão negar.

returnFocus: Retornar o foco ao elemento que invocou o modal após fechá-lo.

customClass: Definir classes CSS customizadas para diferentes elementos do alerta.

timer: Tempo para fechar automaticamente (em milissegundos).

timerProgressBar: Exibir barra de progresso de tempo.

width: Largura do alerta (em qualquer unidade CSS: px, em, %, etc).

padding: Padding interno (em qualquer unidade CSS).

color: Cor do texto (padrão: #545454).

background: Cor de fundo do alerta (padrão: #fff).

animation: Ativar/desativar animações do alerta.

theme: Tema do alerta: light, dark, auto ou borderless.

showClass: Classes CSS para animação de exibição.

hideClass: Classes CSS para animação de ocultação.

target: Elemento container para adicionar o popup (padrão: 'body').

topLayer: Colocar o popup no topo de todos os outros elementos.

input: Tipo de campo input: text, email, password, number, tel, range, textarea, search, url, select, radio, checkbox, file, date, datetime-local, time, week, month.

inputLabel: Rótulo do campo input.

inputPlaceholder: Placeholder do campo input.

inputValue: Valor inicial do input (pode ser uma Promise para alguns tipos).

inputOptions: Objeto com opções para select ou radio (pode ser um Map ou uma Promise).

inputAutoFocus: Focar automaticamente no campo input quando o alerta é exibido.

inputAutoTrim: Remover automaticamente espaços em branco do início e fim do valor do input.

inputAttributes: Atributos HTML adicionais para o input (como min, max, accept, etc).

inputValidator: Função para validar o input, pode ser assíncrona (Promise).

validationMessage: Mensagem de validação personalizada para validadores padrão.

heightAuto: Define se a altura será ajustada automaticamente.

allowOutsideClick: Permitir fechar ao clicar fora do alerta.

allowEscapeKey: Permitir fechar com tecla ESC.

allowEnterKey: Confirmar com tecla ENTER.

stopKeydownPropagation: Impedir propagação de eventos de teclado.

keydownListenerCapture: Configuração para captura de eventos de teclado.

showCloseButton: Exibir botão de fechar no canto superior direito.

closeButtonHtml: Conteúdo HTML do botão de fechar (padrão: '×').

closeButtonAriaLabel: Atributo aria-label para o botão de fechar.

loaderHtml: Conteúdo HTML personalizado para o loader.

showLoaderOnConfirm: Mostrar loading no botão confirmar (usar com preConfirm).

showLoaderOnDeny: Mostrar loading no botão negar (usar com preDeny).

scrollbarPadding: Ajustar padding do corpo quando a barra de rolagem é ocultada.

preConfirm: Função executada antes de confirmar, pode ser assíncrona.

preDeny: Função executada antes de negar, pode ser assíncrona.

returnInputValueOnDeny: Retornar valor do input mesmo em negação.

confirmButtonAriaLabel: Atributo aria-label para o botão confirmar.

denyButtonAriaLabel: Atributo aria-label para o botão negar.

cancelButtonAriaLabel: Atributo aria-label para o botão cancelar.

imageUrl: URL de imagem para exibir no alerta.

imageWidth: Largura da imagem (em qualquer unidade CSS).

imageHeight: Altura da imagem (em qualquer unidade CSS).

imageAlt: Texto alternativo para a imagem.

progressSteps: Array com passos de progresso (útil para filas de alertas).

currentProgressStep: Passo de progresso atual.

progressStepsDistance: Distância entre os passos de progresso.

didRender: Callback executado após o DOM do popup ser atualizado.

willOpen: Callback executado antes do popup ser exibido na tela.

didOpen: Callback executado após o popup ser exibido na tela.

willClose: Callback executado quando o popup é fechado pelo usuário.

didClose: Callback executado após o popup ser descartado pela interação do usuário.

didDestroy: Callback executado após o popup ser destruído.
