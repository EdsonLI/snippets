SweetAlert2 – configuration

title – Título do alerta

text – Texto simples

html – Conteúdo HTML (alterna com text)

icon – Ícone do alerta: success, error, warning, info, question

iconColor – Cor do ícone (ex: #fff)

footer – Conteúdo no rodapé do alerta

backdrop – Fundo escurecido (boolean ou string com URL)

position – Posição do alerta (ex: top-end, center)

grow – Animação de crescimento: row, column, fullscreen

toast – Estilo de toast (fixado no canto)

showConfirmButton – Exibir botão de confirmação

showCancelButton – Exibir botão de cancelar

confirmButtonText – Texto do botão de confirmar

cancelButtonText – Texto do botão de cancelar

denyButtonText – Texto do botão de negação

showDenyButton – Exibir botão de negar

confirmButtonColor – Cor do botão confirmar

cancelButtonColor – Cor do botão cancelar

denyButtonColor – Cor do botão negar

buttonsStyling – Usar os estilos padrões do SweetAlert2

reverseButtons – Inverter posição dos botões

focusConfirm – Foco inicial no botão confirmar

focusCancel – Foco inicial no botão cancelar

focusDeny – Foco inicial no botão negar

customClass – Definir classes CSS customizadas

timer – Tempo para fechar automaticamente (ms)

timerProgressBar – Exibir barra de tempo

width – Largura do alerta

padding – Padding interno

color – Cor do texto

background – Cor de fundo do alerta

input – Tipo de input: text, email, password, select, etc.

inputPlaceholder – Placeholder do campo input

inputValue – Valor inicial do input

inputOptions – Objeto com opções para select ou radio

inputAttributes – Atributos HTML adicionais para o input

inputLabel – Rótulo do campo input

validationMessage – Mensagem de validação personalizada

allowOutsideClick – Fechar ao clicar fora

allowEscapeKey – Fechar com tecla ESC

allowEnterKey – Confirmar com tecla ENTER

stopKeydownPropagation – Impedir propagação de teclas

showLoaderOnConfirm – Mostra loading no botão confirmar

preConfirm – Função chamada antes de confirmar

preDeny – Função chamada antes de negar

returnInputValueOnDeny – Retornar valor do input mesmo em negação

imageUrl – URL de imagem no corpo do alerta

imageWidth – Largura da imagem

imageHeight – Altura da imagem

imageAlt – Texto alternativo da imagem

showClass – Classe usada para exibir o alerta (ex: swal2-show)

hideClass – Classe usada para esconder o alerta (ex: swal2-hide)

didOpen – Callback ao abrir o alerta

didClose – Callback ao fechar o alerta

willOpen – Callback antes de abrir

willClose – Callback antes de fechar

didDestroy – Callback após destruir o alerta
