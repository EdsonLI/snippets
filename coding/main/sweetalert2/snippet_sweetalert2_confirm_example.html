Configuration Params

Here are the keys that you can use if you pass an object into SweetAlert2:

  • title: título principal do modal.
  • text: texto complementar (simples).
  • html: conteúdo HTML personalizado.
  • icon: ícone de status (success, error, warning, info, question).
  • confirmButtonText: texto do botão de confirmação.
  • cancelButtonText: texto do botão de cancelamento (quando usado).
  • showCancelButton: exibe botão de cancelamento (true/false).
  • timer: tempo de exibição antes do alerta fechar automaticamente (em milissegundos).
  • timerProgressBar: exibe uma barra de progresso com o tempo (true/false).
  • input: tipo de entrada (text, email, password, select, etc).
  • inputOptions: opções para o campo select/radio.
  • customClass: permite adicionar classes customizadas aos elementos do modal.
  • allowOutsideClick: permite fechar o alerta clicando fora (true/false).
  • backdrop: fundo do modal (true, false ou string com URL de imagem).
  • position: posição do alerta (top, top-start, center, etc).
  • toast: modo "toast" (alerta discreto no canto da tela).
Exemplo básico
Swal.fire({
  title: 'Bom trabalho!',
  text: 'Você concluiu a tarefa!',
  icon: 'success',
  confirmButtonText: 'Fechar'
})
