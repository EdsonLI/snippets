Git Stash

O stash salva temporariamente modificações que ainda não foram commitadas (em arquivos rastreados) e limpa seu working directory, permitindo que você alterne de branch ou execute outro trabalho sem perder o que estava fazendo e sem fazer o commit.

  • O que exatamente é salvo:
    • Quando você faz git stash:
    • Salva o conteúdo atual dos arquivos modificados
    • Limpa essas alterações do seu diretório de trabalho
    • Não comita nada
    • Permite que você troque de branch com segurança
  • Quando o conteúdo volta:
    • Se você só trocar de branch de volta git checkout minha-branch:
    • O conteúdo dos arquivos continua limpo
    • Nada volta automaticamente
    • O stash continua guardado
  • Para recuperar o conteúdo:
    • Você precisa aplicar o stash manualmente git stash apply:
    • Ou, se quiser aplicar e remover da pilha:git stash pop:
    • Nada volta automaticamente
    • O stash continua guardado
  • O que acontece se você editar arquivos antes de aplicar o stash:
    • Se você alterar algum arquivo que já estava no stash, e depois fizer git stash apply, o Git tentará mesclar as alterações, mas se houver conflito, você verá isso no código (como nos merges)
    • Sem conflito: Git aplica as mudanças normalmente
    • Com conflito: Git marca os trechos conflitantes, e você terá que resolver manualmente
Quando usar?
  • Quando você está no meio de uma tarefa mas precisa mudar para outra branch para corrigir um bug.
  • Quando quer limpar o estado atual do projeto, mas pretende voltar a ele depois.
Comandos básicos
1. Guardar modificações atuais:
 git stash
2. Listar stashes guardados:
 git stash list
3. Restaurar último stash (mantendo na lista):
 git stash apply
4. Aplicar e remover do stash (como "colar e excluir"):
 git stash pop
Remover um stash específico (sem aplicar):
 git stash drop stash@{0}
Remover todos os stashes:
 git stash clear
Exemplo de uso combinado

Você está em branch-a com alterações locais, e precisa mudar para branch-b mas não quer perder suas mudanças nem commitá-las ainda:

 git stash
 git checkout branch-b
 git checkout branch-a
 git stash pop
Dicas avançadas
1. Criar stash com mensagem descritiva:
 git stash push -m "descrição do que estou guardando"
2. Aplicar um stash específico:
 git stash apply stash@{2}
