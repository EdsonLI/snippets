git
Atualizar branch local com o conteúdo atualizado da remota 'development' após PRs e merges
Opção 1: Merge da development na sua branch (mais simples e segura)

Este é o método mais comum em times colaborativos:

  1. Certifique-se de estar na sua branch: 
    git checkout minha-branch
  2. Atualize a branch de base (development): 
    git fetch origin
git checkout development
git pull origin development
  3. Volte para sua branch: 
    git checkout minha-branch
  4. Faça o merge da development atualizada: 
    git merge development
Opção 2: Rebase da sua branch sobre a development (histórico linear, mais avançado)

Este método reorganiza os commits como se sua branch tivesse sido criada agora, em cima da development:

  1. Atualize a branch de base (development): 
    git fetch origin
git checkout development
git pull origin development
  2. Volte para sua branch: 
    git checkout minha-branch
  3. Faça o rebase: 
    git rebase development
    Atenção: Se houver conflitos, resolva-os seguindo as instruções do Git antes de continuar.
  4. Atualize o repositório remoto (se necessário): 
    git push origin minha-branch --force
    Cuidado: O parâmetro --force reescreve o histórico remoto. Use apenas quando entender as implicações.

Dicas úteis:

  • Para comparar versões de um arquivo específico: 
    git log -p -n 3 -- app/control/pedidos/OrderPageClass.php
  • Para visualizar o histórico completo: 
    git log --graph --oneline --all
