Git Stash: Guardar alterações temporariamente sem precisar fazer commit
O que é o Git Stash?

O stash salva temporariamente modificações que ainda não foram commitadas (em arquivos rastreados) e limpa seu working directory, permitindo que você alterne de branch ou execute outro trabalho sem perder o que estava fazendo.

Quando usar?
  • Quando você está no meio de uma tarefa mas precisa mudar para outra branch para corrigir um bug.
  • Quando quer limpar o estado atual do projeto, mas pretende voltar a ele depois.
Comandos básicos
  1. Guardar modificações atuais: 
    git stash
  2. Listar stashes guardados: 
    git stash list
  3. Restaurar último stash (mantendo na lista): 
    git stash apply
  4. Aplicar e remover do stash (como "colar e excluir"): 
    git stash pop
Exemplo de uso combinado

Você está em branch-a com alterações locais, e precisa mudar para branch-b mas não quer perder suas mudanças nem commitá-las ainda:

git stash               # guarda as alterações
git checkout branch-b   # muda de branch
# faz algo na branch-b
git checkout branch-a   # volta
git stash pop           # recupera as alterações
Dicas avançadas
  1. Criar stash com mensagem descritiva: 
    git stash push -m "descrição do que estou guardando"
  2. Aplicar um stash específico: 
    git stash apply stash@{2}
