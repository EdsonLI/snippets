git
Reset hard + force push
1. Faça checkout na branch que vai fazer isso:
 # garante que está na branch certa (ex: main)
 git checkout main
2. Resetar a branch local selecionada para o commit desejado:
 # reseta branch local para o commit desejado
 git reset --hard [hash-do-commit]
3. Enviar para o remoto forçando overwrite:
 # envia para remoto sobrescrevendo
 git push origin main --force
