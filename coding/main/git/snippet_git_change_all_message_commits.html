Reescrever todas as mensagens de commit
1. Execute o comando filter-branch para alterar todas as mensagens:
 git filter-branch --force --msg-filter "echo 'Testing Agent IA Claude Sonnet 3.7'" -- --all
2. Force push para atualizar o repositório remoto:
 git push --force --all
Considerações importantes
  • Esta operação é destrutiva e reescreve o histórico do Git
  • Nunca use em repositórios compartilhados sem avisar os colaboradores
  • Ideal para repositórios pessoais ou antes de tornar um repositório público
  • Todos os colaboradores terão que fazer força na próxima pull
