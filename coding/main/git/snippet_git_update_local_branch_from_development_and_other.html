git
Atualizar branch local com a development (remota) e integrar funcionalidades de outras branches (com 'rebase')

Você precisa:

  • Manter sua branch feature/edson-ajustes atualizada com a branch base development
  • Trazer o código da branch feature/pedro-nova-funcionalidade para testar ou integrar
1: Atualizar sua branch com development
  git switch development
  git fetch origin
  git pull
  git switch feature/edson-ajustes
  git rebase origin/development
Isso garante que a sua branch está atualizada com tudo que foi integrado na development.
2: Integrar o código da branch de outro dev

Você tem duas opções:

Opção 1: Rebase da branch do outro dev (histórico linear)
git switch feature/edson-ajustes
git fetch origin
git rebase origin/feature/pedro-nova-funcionalidade
Útil quando você precisa das alterações como base para seu trabalho.
Opção 2: Merge da branch do outro dev (preserva histórico)
git switch feature/edson-ajustes
git fetch origin
git merge origin/feature/pedro-nova-funcionalidade
Mantém o histórico de que você trouxe os commits dele, mais explícito e seguro para testes.

Resumo:

  • Rebase com development → manter base atualizada
  • Trazer o que outro dev fez (via rebase, merge ou cherry-pick) → integrar dependências específicas
