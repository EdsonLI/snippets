Resolver conflitos localmente no VS Code após criar PR
# 1º a dica extra: se precisar comparar visualmente as 3 últimas versões de um método específico no VS Code tem como, você pode usar o seguinte comando: 
git log -p -n 3 -- app/control/pedidos/OrderPageForm.php
# Atualizar a branch de base (development): 
git checkout development
    git pull origin development
# Fazer checkout da sua branch da PR: 
  
  git checkout 157-implementar-a-nova-funcionalidade
Ou, se ainda não tiver localmente: 
  
  git fetch origin
  git checkout -b 157-implementar-a-nova-funcionalidade
# Mesclar a branch development na sua para resolver os conflitos: 
  
  git merge development
# Resolver os conflitos: Ir até a aba 'Source Control' (atalho: Ctrl+Shift+G) Abrir os arquivos com ícone de exclamação ⚠️ Usar os botões: Accept Current (HEAD) [Aceitar atual] / Incoming [Vindo da branch remota] / Both Changes [Mesclar as duas] Remover os marcadores de conflito se necessário Atual x Entrada: "Atual" (HEAD) → É o que está na sua branch atual - normalmente a da PR "Entrada" ou "Incoming" é o que vem da 'development' (ou qualquer branch que você está tentando mesclar) # Finalizar o merge: 
  
  git add .
  git commit -m "Resolvendo conflitos com a branch development"
Atualize sua PR com o push: 
git push origin 157-implementar-a-funcionalidade-de-armazenamento-de-arquivos-em-cloud-storage
✅ PR atualizada e pronta para nova revisão!
