Resolver conflitos localmente no VS Code após criar PR
1. Atualize a branch de base (development):
 git checkout development
 git pull origin development
2. Faça checkout da sua branch da PR:
 git checkout 157-implementar-a-nova-funcionalidade
Se ainda não tiver localmente:
 git fetch origin
 git checkout -b 157-implementar-a-nova-funcionalidade origin/157-implementar-a-nova-funcionalidade
3. Mescle a branch development na sua para resolver os conflitos:
 git merge development
4. Resolva os conflitos no VS Code:
  • Acesse a aba Source Control (Ctrl+Shift+G);
  • Abra os arquivos com ícone de exclamação ⚠
  • Use os botões:
    Accept Current (HEAD) / Accept Incoming / Accept Both Changes:
    Atual (HEAD): sua branch atual (geralmente a da PR)
    Entrada (Incoming): o que vem da development

5. Após resolver finalize o merge:
 git add .
 git commit -m "Resolvendo conflitos com a branch development"
6. Push para o repositório remoto:
 git push origin 157-implementar-a-nova-funcionalidade

Comparar visualmente as três últimas versões
 git log -p -n 3 -- app/control/pedidos/OrderFormView.php
Comparar versões com GitLens
  1. Instale a extensão GitLens no VS Code;
  2. Abra o arquivo desejado;
  3. Clique com o direito > Open File History (ou use o painel lateral do GitLens);
  4. Veja a lista de commits que modificaram o arquivo;
  5. Clique em um commit e selecione Open Revision;
  6. Abra as últimas 3 revisões e organize lado a lado (Ctrl+\ para split editor).
