Resolver conflitos localmente no VS Code após criar PR
Passo a passo: Resolver conflitos da PR no VS Code

    
  
  1. Atualize a branch de base (development):
    git checkout development
    git pull origin development
  
    2. 
  
  2. Faça checkout da sua branch da PR:
    git checkout 157-implementar-a-nova-funcionalidade

    
    Ou, se ainda não tiver localmente:
    
    git fetch origin
    git checkout -b 157-implementar-a-nova-funcionalidade
  
    3. 
  
  3. Mescle a branch development na sua para resolver os conflitos:
    git merge development
  
    4. 
  
  4. Resolva os conflitos:
    
      
      
    • Vá até a aba Source Control (atalho: Ctrl+Shift+G)
      • 
      
    • Abra os arquivos com ícone de exclamação ⚠️
      • 
      
    • Use os botões: Accept Current [Aceitar alteração local] / Incoming [Vindo da branch remota] / Both Changes [Mesclar as duas]
      • 
      
    • Remova os marcadores de conflito se necessário
      • 
    
    
  
    5. 
  
  5. Entrada x Atual:
    
      
      
    • "Entrada" ou "Incoming" é o que vem da development (ou qualquer branch que você está tentando mesclar)
      • 
      
    • "Atual" (HEAD) → É o que está na sua branch atual - normalmente a da PR
      • 
    
    
  
    6. 
  
  6. Finalize o merge:
    git add .
    git commit -m "Resolve conflitos com a branch development"
  
    7. 
  
  7. Atualize sua PR com o push:
    git push origin 157-implementar-a-funcionalidade-de-armazenamento-de-arquivos-em-cloud-storage
  
    8. 



✅ PR atualizada e pronta para nova revisão!
