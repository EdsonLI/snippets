Snippets PHP

  • 🔐 Senha segura com hash 
    
$senha = 'minhasenha123';
$hash = password_hash($senha, PASSWORD_DEFAULT);
// Para verificar depois:
if (password_verify('minhasenha123', $hash)) {
    echo 'Senha correta!';
}
  • 📦 Conectar ao MySQL com PDO 
    
try {
    $pdo = new PDO("mysql:host=localhost;dbname=meubanco", "usuario", "senha");
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Conectado com sucesso!";
} catch (PDOException $e) {
    echo "Erro: " . $e->getMessage();
}
  • 📬 Enviar e-mail simples com mail() 
    
$para = "exemplo@email.com";
$assunto = "Assunto do e-mail";
$mensagem = "Olá! Isso é um teste.";
$headers = "From: contato@seudominio.com";

mail($para, $assunto, $mensagem, $headers);
