Voltar commits (desfazer ou reverter)

Situação Comando Descrição
Voltar 1 commit local (mantém alterações) git reset --soft HEAD~1 Volta 1 commit, mas preserva o código no stage.
Voltar 1 commit local (mantém no working dir) git reset --mixed HEAD~1 Volta o commit e tira do stage.
Voltar 1 commit e descartar tudo git reset --hard HEAD~1 Cuidado! Apaga commit e alterações.
Voltar 2, 3 ou mais commits git reset --hard HEAD~2 Basta ajustar o número.
Reverter um commit (sem apagar histórico) git revert <hash> Cria novo commit que desfaz um anterior. Ideal em repos colaborativos.
