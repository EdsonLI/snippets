🔙 Voltar commits

Situação
Comando
Descrição
Voltar 1 commit local (mantém alterações)
git reset --soft HEAD~1
Volta 1 commit, mas preserva o código no stage.
Voltar 1 commit local (mantém no working dir)
git reset --mixed HEAD~1
Volta o commit e tira do stage.
Voltar 1 commit e descartar tudo
git reset --hard HEAD~1
Cuidado! Apaga commit e alterações.
Voltar 2, 3 ou mais commits
git reset --hard HEAD~2
Basta ajustar o número (HEAD~3, etc).
Reverter um commit (sem apagar histórico)
git revert <hash>
Cria novo commit que desfaz um anterior. Ideal para colaboração.

📂 Branches

Situação
Comando
Descrição
Criar branch nova
git checkout -b nome-da-branch
Usa-se para tarefas novas.
Alternar entre branches
git checkout nome-da-branch
Muda de contexto.
Subir branch para o repositório
git push -u origin nome-da-branch
-u define upstream para facilitar pushes futuros.
Deletar branch local
git branch -d nome-da-branch
Use -D para forçar a exclusão.
Deletar branch remota
git push origin --delete nome-da-branch
Para limpar branches antigas do repositório remoto.

🔄 Atualizar com development

Situação
Comando
Descrição
Atualizar sua branch com commits da development
git checkout sua-branch
git pull origin development
Garante que sua branch esteja atualizada antes do PR.
Rebase para reordenar histórico
git rebase development
Cria histórico linear, mas pode gerar conflitos.

🔍 Ver histórico e estado

Situação
Comando
Descrição
Ver log resumido e visual
git log --oneline --graph --all
Visualização clara do histórico e branches.
Ver mudanças locais
git status
Mostra alterações e arquivos no stage.
Ver diferenças no código
git diff
Compara working dir com o último commit.
