Como Implementar

Siga estas etapas para implementar os cards com altura uniforme em seu sistema:

  1. Adicione as referências CSS e JavaScript nas páginas necessárias
  2. Aplique a classe h-100 aos cards existentes
  3. Para novos cards Bootstrap, use a estrutura demonstrada acima

O script uniform-height-cards.js aplica automaticamente as classes necessárias e gerencia vídeos lazy load.
