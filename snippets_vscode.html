Como usar estes snippets no VS Code:

- Acesse a pasta de snippets do VS Code: Windows+R e cole: %APPDATA%\Code\User\snippets
- Cole ou mova os arquivos .code-snippets para a pasta...
 - Para utilizar no VS Code é simples: ao começar a digitar, o autocompletar do VS Code já vai trazer sugestões de acordo com os snippets que você já tem, ao visualizar o 'prefixo' do qual quer utilizar, selecione e confirme com Enter para gerar o código.
