Como usar estes snippets no VSCode

  1. Acesse a pasta de snippets do VSCode:
    Pressione Windows+R e cole: %APPDATA%\Code\User\snippets
  2. Cole os arquivos .code-snippets nessa pasta...
  3. Para utilizar no VS Code é simples:
    Ao começar a digitar o prefixo, o autocompletar do VS Code já vai trazer sugestões de acordo com os snippets que você já tem... Ao identificar qual quer utilizar, coloque a seleção sobre ele e clique Enter para aplicar
Para criar ou editar snippets, utilize apenas arquivos .code-snippets nesta pasta.
