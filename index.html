Cookies, Sessões e Preferências
PHP HTML 
<?php
   session_start();

   // Aceite de cookies recebido via POST
   if (isset($_POST['aceitar'])) {
      setcookie('aceite_cookie', '1', time() + (86400 * 30), '/'); // 30 dias
      $_SESSION['tema'] = 'escuro'; // Exemplo de preferência
   }

   // Mostrar sessão e cookie (debug/uso)
   if (isset($_COOKIE['aceite_cookie'])) {
      echo "Cookie aceite_cookie: " . $_COOKIE['aceite_cookie'] . "<br>";
   }

   if (isset($_SESSION['tema'])) {
      echo "Sessão tema: " . $_SESSION['tema'] . "<br>";
   }
?>

<!-- Mostrar aviso se cookie ainda não aceito -->
<?php if (!isset($_COOKIE['aceite_cookie'])): ?>
   <form method="post" style="position: fixed; bottom: 1rem; left: 1rem; right: 1rem; background: #222; color: #fff; padding: 1rem; border-radius: .5rem; z-index: 1000;">
      Este site usa cookies para salvar suas preferências.
      <button type="submit" name="aceitar" class="btn btn-sm btn-success ms-2">Aceitar</button>
   </form>
<?php endif; ?>

jQuery 
$(function() {
  var $grid = $('.grid').isotope({
    itemSelector: '.grid-item',
    layoutMode: 'fitRows',
  });

  $('.controls').on('click', 'button', function() {
    $('.controls button').removeClass('active');
    $(this).addClass('active');
    var filterValue = $(this).attr('data-filter');
    $grid.isotope({ filter: filterValue });
  });
});

Git - Branches
Git 
        
          # 1. Baixar o conteúdo de uma branch remota:
          # Use o comando `git fetch` para baixar os dados da branch remota sem alternar para ela imediatamente:
          git fetch origin nome-da-branch

          # Ou, se você deseja baixar os dados e já alternar para a branch remota, use o comando `git checkout` (ou `git switch`):
          git checkout nome-da-branch

          # Se a branch ainda não existir localmente, o Git irá criar uma branch local que rastreia a branch remota.

          # 2. Criar a branch e alternar para ela de forma explícita:
          # Para criar a branch localmente antes de alternar para ela, utilize:
          git branch nome-da-branch origin/nome-da-branch
          git checkout nome-da-branch

          # Ou em um único comando:
          git checkout -b nome-da-branch origin/nome-da-branch

          # A partir do Git 2.23, pode-se usar `git switch`:
          git switch -c nome-da-branch origin/nome-da-branch

          # 3. Alternar entre branches existentes:
          # Se a branch já existir localmente, utilize:
          git checkout nome-da-branch

          # Ou:
          git switch nome-da-branch

          # 4. Atualizar a branch local com os dados remotos:
          # Para garantir que a branch está atualizada:
          git pull
Manipulação avançada de datas com PHP
PHP Date/Time 
<?php

// Data atual
$agora = new DateTime('now', new DateTimeZone('America/Sao_Paulo'));
echo "Agora (BR): " . $agora->format('d/m/Y H:i:s') . "<br>";
echo "ISO: " . $agora->format(DateTime::ATOM) . "<br><br>";

// Criando a partir de string
$nascimento = DateTime::createFromFormat('d/m/Y', '05/08/1990');
echo "Nascimento: " . $nascimento->format('Y-m-d') . "<br>";

// Diferença entre datas
$diff = $nascimento->diff($agora);
echo "Idade: " . $diff->y . " anos, " . $diff->m . " meses<br><br>";

// Adição e subtração
$hoje = new DateTime();
$hoje->add(new DateInterval('P10D')); // +10 dias
echo "10 dias no futuro: " . $hoje->format('d/m/Y') . "<br>";

$hoje->sub(new DateInterval('P1M')); // -1 mês
echo "Menos 1 mês: " . $hoje->format('d/m/Y') . "<br><br>";

// Loop de datas (DatePeriod)
$inicio = new DateTime('2025-01-01');
$fim = new DateTime('2025-01-10');
$intervalo = new DateInterval('P2D');

$periodo = new DatePeriod($inicio, $intervalo, $fim);
foreach ($periodo as $data) {
   echo "Dia: " . $data->format('d/m/Y') . "<br>";
}

echo "<br>";

// Timezones
$utc = new DateTime('now', new DateTimeZone('UTC'));
echo "UTC: " . $utc->format('H:i:s \\U\\T\\C') . "<br>";

// Timestamp para DateTime
$dataUnix = (new DateTime())->setTimestamp(1720000000);
echo "Convertido de timestamp: " . $dataUnix->format('d/m/Y H:i') . "<br>";

// DateTimeImmutable
$dataFixa = new DateTimeImmutable('2025-06-28');
$nova = $dataFixa->add(new DateInterval('P1Y'));
echo "Data original: " . $dataFixa->format('d/m/Y') . "<br>";
echo "Mais 1 ano (immutável): " . $nova->format('d/m/Y') . "<br>";

?>
Consulta avançada com PDO e filtro LIKE
PHP SQL 
<?php

// Função para criar conexão segura
function getConnection(): PDO {
   $host = 'localhost';
   $db = 'teste';
   $user = 'root';
   $pass = '';
   $charset = 'utf8mb4';

   $dsn = "mysql:host=$host;dbname=$db;charset=$charset";
   $options = [
      PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
      PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_OBJ,
      PDO::ATTR_EMULATE_PREPARES   => false,
   ];

   return new PDO($dsn, $user, $pass, $options);
}

try {
   $pdo = getConnection();

   // Filtro dinâmico
   $filtro = 'ana';

   $stmt = $pdo->prepare("SELECT id, nome, email FROM usuarios WHERE nome LIKE :nome");
   $stmt->bindValue(':nome', '%' . $filtro . '%', PDO::PARAM_STR);
   $stmt->execute();

   $usuarios = $stmt->fetchAll();

   if ($usuarios) {
      foreach ($usuarios as $u) {
         echo "ID: $u->id <br>";
         echo "Nome: $u->nome <br>";
         echo "Email: $u->email <br><hr>";
      }
   } else {
      echo "Nenhum resultado encontrado.";
   }

} catch (PDOException $e) {
   echo "Erro: " . $e->getMessage();
}

?>

Cookies com PHP (básico ao avançado)
PHP 
<?php

   // Criar um cookie simples (dura 1 hora)
   setcookie('usuario', 'Edson', time() + 3600);

   // Verificar se o cookie existe
   if (isset($_COOKIE['usuario'])) {
      echo "Bem-vindo, " . $_COOKIE['usuario'];
   } else {
      echo "Usuário desconhecido.";
   }

   // Apagar um cookie (expira no passado)
   setcookie('usuario', '', time() - 3600);

   // Cookie com parâmetros avançados (segurança + domínio)
   setcookie(
      name: 'sessao_segura',
      value: 'abc123',
      expires_or_options: [
         'expires' => time() + 3600,
         'path' => '/',
         'domain' => 'exemplo.com.br',
         'secure' => true,      // Só HTTPS
         'httponly' => true,    // Inacessível via JavaScript
         'samesite' => 'Strict' // Proteção contra CSRF
      ]
   );
?>
Métodos Estáticos vs Não Estáticos
PHP 
<?php

   class Saudacao {
      public function ola() {
         return "Olá do método NÃO estático!";
      }

      public static function olaStatic() {
         return "Olá do método ESTÁTICO!";
      }
   }

   // Método não estático → requer instância
   $exemplo = new Saudacao();
   echo $exemplo->ola(); // OK

   // Método estático → chamado diretamente da classe
   echo Saudacao::olaStatic(); // OK

   // echo Saudacao::ola(); // Erro: não estático chamado estaticamente
?>
isset vs empty em PHP
PHP 
<?php
   $variavel1 = '';
   $variavel2 = 0;
   $variavel3 = null;

   // isset verifica se a variável existe e não é null
   var_dump(isset($variavel1)); // true
   var_dump(isset($variavel2)); // true
   var_dump(isset($variavel3)); // false

   // empty verifica se a variável é vazia ou inexistente
   var_dump(empty($variavel1)); // true

Convertendo a partir de float
PHP 
<?php

   function foo($value): int {
      return $value;
   }

   var_dump(foo(8.1)); // Descontinuado: conversão implícita de float 8.1 para int perdendo precisão a partir do PHP 8.1.0
   var_dump(foo(8.1)); // 8 antes do PHP 8.1.0
   var_dump(foo(8.0)); // 8 em ambos os casos

   var_dump((int) 8.1);     // 8 em ambos os casos
   var_dump(intval(8.1));   // 8 em ambos os casos
?>
